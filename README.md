# FORCA project page

Project page for **FORCA: A Force-Aware Coding Agent for Contact-Rich Robot Manipulation**
(Xiao Tan, Yixuan Wang, Zhexi Wang, Wenzhen Yuan; UIUC). Live at https://tanoom.github.io/forca/

Built from the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## Edit
- All content is in `index.html`. Search for `TODO` for the arXiv ID placeholders (Paper/arXiv buttons, BibTeX, citation meta).
- Figures (cropped from the RA-L submission) are in `static/images/`, the narrated video, captions and poster in `static/videos/`.
- Page-specific styles are at the bottom of `static/css/index.css`.

## Preview locally
```
python3 -m http.server 8000
```
Then open http://localhost:8000

## Publish
Commit and push to `main`; GitHub Pages redeploys in about a minute.
