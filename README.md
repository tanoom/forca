# FORCA project page

Project page for the FORCA paper, built from the
[Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## Edit
- All content is in `index.html`. Search for `TODO` to find every placeholder.
- Images go in `static/images/`, videos in `static/videos/`, PDFs in `static/pdfs/`.
- Replace `static/images/favicon.ico` with your own icon.

## Preview locally
```
python3 -m http.server 8000
```
Then open http://localhost:8000

## Publish
Push to GitHub, then Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
The site is served at `https://<username>.github.io/forca/`.
