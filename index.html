Abstract

Coding agents can translate language instructions into robot programs. For contact-rich manipulation, a key challenge is to generate and refine control logic that responds to physical interaction. We present FORCA, a coding agent that takes visual observations and wrist force/torque (F/T) measurements as input to write Python programs for contact probing and force-responsive motion. Between executions, the agent inspects force records alongside visual outcomes to diagnose failures and revise both motion and force-feedback control logic. FORCA requires no demonstrations, task-specific training, or simulation. Across five real-robot tasks, we demonstrate its effectiveness in three forms of contact-rich manipulation: improving manipulation accuracy, adapting to changes in object or surface properties, and regulating contact under surface variation and object motion. Compared with a vision-only variant of the same agent, FORCA improves grasp accuracy and task success and reduces contact loss in wiping and peeling.

Method

Given a language instruction and RGB-D observations, FORCA writes a complete Python task program with access to the measured wrist wrench. The program runs on the robot without querying the foundation model. After execution, the agent reviews the recorded interaction and revises the code. The approach has three parts:

  1. Force-aware program synthesis. Starting from a skill codebase for perception, grasping and motion planning, the agent writes the force-dependent logic for each task, such as when an approach should stop or how motion should respond to a force error.
  2. Contact-responsive execution. During a rollout, contact probes refine geometric estimates (surface height, grasp position), and a 100 Hz loop reads the wrench and updates Cartesian velocity commands for actions that need sustained contact.
  3. Execution-grounded revision. Between rollouts, the agent relates force events in the recorded trace to robot motion and visible outcomes, then revises parameters, contact conditions, control logic or the action sequence.

Results

Five real-robot tasks on a UR5e with a wrist F/T sensor, grouped by how force feedback helps. The baseline is a vision-only variant of the same agent with the same foundation model, instructions and skills, but no access to force data.

1. Precise manipulation: drawer opening and door-handle operation

The drawer is transparent, so its handle is hard to localize from vision alone. FORCA probes the handle and door panel to refine the grasp pose before acting.

2. Adapting to new physical conditions: cube-to-target

The robot knocks an object so it slides into a target region. FORCA first builds a knocking program from scratch for a cube on a whiteboard (13 iterations). We then swap in a cylinder (61.9 g vs. 663.6 g) or a woodboard surface with different friction. Continuing from the retained program, FORCA reaches the target band within about 2 additional revisions in each new configuration.

3. Online contact regulation: vase wiping and cucumber peeling

Vase wiping. Both agents refine their programs on a static vase, then run them without further revision on a vase that a person moves and rotates. The vision-only program's tuned offsets stop working once the vase moves; FORCA follows the moving surface with force feedback.

How the program evolves: door-handle case study

FORCA failed mostly at press down: the handle turned but the latch did not release. It found the latch release and end stop as a sharp rise in resistance in the recorded press force, then fixed the remaining failures in pulling and releasing.

The vision-only agent failed mostly at grasp and pull open. It could press the handle down, but the handle kept slipping out of the gripper before the door opened.
